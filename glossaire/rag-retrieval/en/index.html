RAG

Retrieval-Increased Generation. Technique linking an LLM to an external knowledge base to produce more accurate and factual responses.

🎯 Why it matters
This recovery step is the internal search engine of AI. Without it, the model would only guess answers from its frozen knowledge, while with it, it instantly accesses the exact information it needs.
💡 Concrete example
A company AI assistant using RAG can respond from internal documents without hallucinating.
⚙️ In practice
Recovery is based on encoding the user's question as a vector. This vector is compared with the knowledge base using similarity measurements to extract the most relevant documents. Advanced techniques such as "re-ranking" allow these results to be reordered in order to transmit only the most crucial data to the model.
Common mistake: Confound semantic vector search with a simple keyword search, which does not understand the meaning of sentences.
