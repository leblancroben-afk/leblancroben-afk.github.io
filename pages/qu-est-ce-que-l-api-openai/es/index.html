¿Cuál es la API de OpenAI?

Respuesta corta

La API OpenAI es una interfaz de programación que integra los modelos de inteligencia artificial de OpenAI en un sitio, aplicación o software. Puede generar texto, analizar documentos, crear imágenes, procesar tareas de audio y automatizar.

¿Cuál es la API de OpenAI?

La API OpenAI es una interfaz de programación que permite a los desarrolladores utilizar los modelos de inteligencia artificial de OpenAI en sus propias aplicaciones, sitios web o software.

  • Actúa como puente entre su aplicación y los modelos OpenAI.
  • Le permite enviar una solicitud, como una pregunta o una declaración, y luego recibir una respuesta generada por AI.
  • Normalmente funciona a través de solicitudes HTTP autenticadas por una clave API.
  • Se puede utilizar para crear chatbots, generar contenido, resumir documentos, analizar datos o automatizar tareas.
  • A diferencia de ChatGPT, la API no proporciona una interfaz lista para usar: está destinada a la integración técnica.

¿Cómo conseguir una clave OpenAI API?

Para obtener una clave de OpenAI API, crear una cuenta en la plataforma OpenAI, acceder a la gestión de su organización, crear o seleccionar un proyecto, y luego generar una clave secreta en la sección Claves de API.

  • Conectarse a la plataforma OpenAI.
  • Acceda a la configuración de su organización.
  • Crear un proyecto o seleccionar un proyecto existente.
  • Abra la sección Claves de API del proyecto.
  • Haga clic en "Crear nueva clave secreta".
  • Copiar la clave inmediatamente y guardarla a un administrador de contraseñas, una caja fuerte secreta o una variable de entorno seguro.
  • Dar a la llave los permisos más limitados posibles según el uso previsto.

OpenAI indica que la clave secreta ya no puede ser vista después de su creación. Si lo pierdes, necesitas generar uno nuevo y actualizar tu aplicación.

  • Cada proyecto tiene sus propias claves de API.
  • Una llave puede tener permisos "All", "Restricted" o "Read Only".
  • Para la integración profesional, prefiera una clave restringida más que una clave con todos los derechos.
  • Nunca guarde la clave directamente en el código fuente, en un archivo público o en una aplicación móvil.
  • Utilizar preferentemente un servicio de gestión de entornos variables o secretos.

Antes de poner la integración en la producción, probar la clave con una simple solicitud, comprobar los límites de flujo de su proyecto y establecer un seguimiento de gastos.

¿Cuál es la diferencia entre ChatGPT y OpenAI API?

ChatGPT es una aplicación lista para el usuario, mientras que la API OpenAI es una interfaz para los desarrolladores para integrar los modelos OpenAI en sus propios sitios, aplicaciones o software.

  • ChatGPT se utiliza directamente en una interfaz de conversación.
  • La API OpenAI se utiliza desde un sitio, aplicación móvil, software o sistema automatizado.
  • ChatGPT es adecuado para la escritura, investigación, almacenamiento de cerebros o asistencia diaria.
  • La API es adecuada para crear un chatbot cliente, asistente interno, herramienta de generación de contenido o automatización.
  • Con la API, la empresa conserva más control sobre la experiencia de usuario, datos enviados, modelos llamados e integración en sus herramientas.
  • La facturación de API está separada de la suscripción de ChatGPT.

En la práctica, una empresa puede utilizar ChatGPT para sus equipos y OpenAI API para ofrecer funcionalidad de IA a sus clientes, automatizar un proceso o conectar IA a su CRM, sitio de comercio electrónico o software interno.

¿Se paga la API OpenAI?

Sí, el uso de la API de OpenAI suele pagar. Para iniciar un uso pagado, agregue un método de pago en la configuración de facturación de su cuenta API. Esta factura está separada de su suscripción a ChatGPT.

  • El costo depende principalmente del modelo elegido, la funcionalidad utilizada y el volumen de fichas consumidas.
  • Las fichas de entrada corresponden a los elementos enviados a la plantilla en la consulta.
  • Las fichas de salida corresponden a los elementos generados por el modelo en la respuesta.
  • Las fichas en caché pueden beneficiarse de un precio diferente gracias a la rápida ocultación.
  • Para algunos modelos de razonamiento, las fichas de razonamiento no son visibles en la respuesta, sino que cuentan en el uso de salida.
  • El uso de herramientas, almacenamiento o características específicas puede resultar en facturación separada.

Una ficha puede representar un personaje, una parte de una palabra, una palabra entera o un signo de puntuación. Así que no corresponde exactamente a una palabra.

Para controlar el presupuesto, establecer un presupuesto mensual, activar umbrales de alerta, monitorear el consumo en el panel de control de OpenAI y limitar llamadas innecesarias. En particular, OpenAI recomienda establecer varios umbrales de gastos, como el 90% y el 95% de un presupuesto mensual.

También existen límites de flujo. Pueden expresarse como solicitudes por minuto, fichas por minuto, consultas por día o fichas por día, dependiendo del modelo y el nivel de uso. Se definen a nivel de organización y proyecto, no a nivel de usuario individual.

¿Cómo asegurar una clave OpenAI API?

Para asegurar una clave de OpenAI API, nunca compartirla públicamente, almacenarla en un gestor de entorno variable o secreto, asignarle permisos limitados, supervisar su uso y revocarlo inmediatamente en caso de fuga.

  • Nunca publicar la clave en un GitHub, GitLab, foro, documentación pública, correo electrónico o captura de pantalla.
  • No lo incluya directamente en el código de una aplicación móvil, sitio web público o archivo JavaScript que sea accesible en el lado del navegador.
  • Almacene la llave en una variable de entorno lado servidor o en un servicio de gestión secreto.
  • Dar cada permiso mínimo clave.
  • Crear una clave separada por proyecto, entorno o aplicación para limitar el impacto en caso de compromiso.
  • Supervisar el uso y los costos regularmente para detectar actividad anormal.
  • Establecer límites de gasto y umbrales de alerta.
  • Renovar las llaves periódicamente eliminando las viejas y creando nuevas llaves.
  • Revise el código antes de introducirlo en un repositorio público para asegurarse de que no se haya incluido ninguna llave.
  • Tenga cuidado con herramientas de terceros, bibliotecas y plataformas que soliciten acceso a su clave API.

Si una clave ha sido expuesta, eliminarla inmediatamente desde el panel OpenAI, crear una nueva, actualizar su aplicación y revisar el historial de uso para identificar una actividad inusual.

La API OpenAI utiliza autenticación Bearer: la clave se transmite en el encabezado HTTP Authority. Debe ser cargado desde un servicio de gestión de entorno variable o secreto en el servidor, no desde el código lado cliente.
