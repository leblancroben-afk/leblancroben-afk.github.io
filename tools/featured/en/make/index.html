What is Make?

Formerly known as Integromat, Make has become the standard for process automation without code (No-Code). Its unique visual interface allows to design, build and automate workflows by linking applications between them like Lego bricks.

Unlike basic linear solutions, Make excels in complexity. You can create infinite plug-ins, iterate to element lists, transform text or date formats on the fly, and configure backup systems in case of network error.

With the advent of general AI, Make is the perfect tool to create autonomous agents. For example, you can listen to the arrival of a new customer review, ask ChatGPT to analyze the feeling, and then write and send a personalized reply automatically by e-mail or Slack.
