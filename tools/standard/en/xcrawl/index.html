About XCrawl

XCrawl is an API platform designed to collect and structure data from the web. A developer sends a public URL or search request, then receives cleaned content in Markdown, JSON, HTML or screenshot format.

The solution supports JavaScript rendering, rotation of residential proxies and new automatic attempts to facilitate extraction on dynamic or protected sites. XCrawl also offers APIs dedicated to unit scraping, multi-page crawl, domain mapping and SERP results recovery.

XCrawl is particularly well integrated with IA applications: its Markdown and JSON outputs are suitable for RAG pipelines, conversational agents and language models. The platform provides Python and Node.js SDKs, a CLI, an MCP server and a n8n node.

Strengths and limitations

  • JavaScript rendering and dynamic site management via headless browser.

  • SDK Python and Node.js, CLI, MCP server and n8n node.

Limitations

  • Mainly technical use: API, development or automation.
