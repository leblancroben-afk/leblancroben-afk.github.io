À propos de XCrawl

XCrawl est une plateforme d’API conçue pour collecter et structurer des données issues du web. Un développeur envoie une URL publique ou une requête de recherche, puis reçoit un contenu nettoyé au format Markdown, JSON, HTML ou une capture d’écran.

La solution prend en charge le rendu JavaScript, la rotation de proxies résidentiels et les nouvelles tentatives automatiques, afin de faciliter l’extraction sur des sites dynamiques ou protégés. XCrawl propose également des API dédiées au scraping unitaire, au crawl multi-pages, à la cartographie de domaines et à la récupération de résultats SERP.

XCrawl s’intègre particulièrement bien aux applications IA : ses sorties Markdown et JSON sont adaptées aux pipelines RAG, aux agents conversationnels et aux modèles de langage. La plateforme fournit des SDK Python et Node.js, un CLI, un serveur MCP ainsi qu’un nœud n8n.

Fonctionnalités principales

Scrape API

Extrait une page web en JSON, Markdown, HTML ou capture d’écran en une requête.

Search API

Récupère des résultats de moteurs de recherche sous forme de données SERP structurées.

Crawl API

Explore plusieurs pages d’un site avec contrôle de profondeur et de périmètre.

Map API

Cartographie les URLs découvrables d’un domaine et révèle sa structure.

Sorties prêtes pour l’IA

Fournit du Markdown et du JSON propres pour RAG, agents IA et LLM.

Intégrations

Se connecte à MCP, n8n, Zapier, Make et pipelines personnalisés.

Avantages et limites

Points forts

  • Extraction de pages web en Markdown, JSON, HTML ou captures d’écran.
  • API Scrape, Crawl, Map et Search/SERP dans une même plateforme.
  • Rendu JavaScript et gestion des sites dynamiques via navigateur headless.
  • Proxies résidentiels rotatifs, empreintes de navigateur et relances intégrées.
  • SDK Python et Node.js, CLI, serveur MCP et nœud n8n.
  • 1 000 crédits gratuits à l’inscription, sans carte bancaire.

Limites

  • Usage principalement technique : API, développement ou automatisation.
  • La consommation de crédits varie selon la complexité de la requête et les fonctionnalités utilisées.
  • L’extraction de données doit respecter les conditions d’utilisation, droits d’auteur et règles des sites ciblés.
  • Les informations de tarification détaillées ne sont pas affichées publiquement de façon claire sur la page d’accueil consultée.

Idées d'utilisation

  • Alimenter un assistant IA avec la documentation à jour d’un produit
  • Créer une base de connaissances RAG à partir d’articles ou de pages de support
  • Surveiller les prix, produits et pages concurrents
  • Extraire des résultats Google pour le suivi SEO et l’analyse de mots-clés
  • Collecter des avis clients structurés pour l’analyse de sentiment
  • Automatiser la veille concurrentielle et la veille média
